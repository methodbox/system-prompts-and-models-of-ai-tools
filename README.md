# System Prompts and Models of AI Tools

This is a direct fork of the original repo for my own preservation purposes only.

## *AI Overview*

### Description

The open-source repository System Prompts and Models of AI Tools collects and documents hidden system prompts, JSON tool-use schemas, and model configurations for over 28 major AI coding tools and assistants.

### Key Features of the Repository

* Real Operating Instructions: Rather than relying on public marketing copy, the repository exposes the actual behind-the-scenes natural language prompts and rulebooks sent to underlying frontier models.

* Tool-Use Schemas: It includes JSON tool definitions showing what file systems, terminals, and external APIs each agent is given permission to access.

* Tracked AI Tools: Covers prominent agents and coding platforms such as Cursor, Claude Code, Windsurf, Devin AI, Augment Code, v0, Perplexity, Replit, and Lovable.

* Transparency & Security: The collection serves as a core reference for developers and researchers studying prompt engineering, agent behavior, and how software vendors handle guardrails and context persistence.
